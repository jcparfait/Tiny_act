# Tiny Act

> Version mobile en cours de finalisation pour presentation recruteur.

La version a regarder en priorite est l'application mobile Expo / React Native sur la branche [`mobile/expo-client`](https://github.com/jcparfait/Tiny_act/tree/mobile/expo-client).

La branche `master` contient encore l'historique Rails/web du projet. Elle reste utile pour le backend Rails et l'evolution du produit, mais elle ne doit pas etre confondue avec la version mobile actuelle.

## Ou regarder

- Branche mobile : [`mobile/expo-client`](https://github.com/jcparfait/Tiny_act/tree/mobile/expo-client)
- Application mobile : [`mobile/`](https://github.com/jcparfait/Tiny_act/tree/mobile/expo-client/mobile)
- Backend/API Rails : racine du projet sur la meme branche

## Stack de la version mobile

- Expo / React Native
- TypeScript
- Expo Router
- Rails 8.1 en API JSON
- PostgreSQL
- Authentification mobile par token

Le README complet, les instructions d'installation, les tests, le deploiement Heroku et la generation APK seront nettoyes dans les prochaines etapes.
